# data/

샘플 문서, 라벨링 테스트셋, 실험 데이터를 두는 곳입니다.

## 이 폴더는 git 에 올라가지 않습니다

`.gitignore`로 막아두었습니다. `data/README.md`와 `data/.gitkeep`만 예외입니다.

여기에는 팀원 본인의 **강의계획서·이수내역·메일·시간표**가 들어갑니다.
계획서 4.2 원칙에 따라 **본인 동의 하에서만 사용하고 외부에 공개하지 않습니다.**

## 권장 구조

```text
data/
├── raw/           원본 문서 (수집한 그대로)
├── interim/       중간 처리 결과
├── processed/     전처리 완료
└── testset/       라벨링된 평가용 테스트셋 (계획서 4.2, 50건 이상)
```

## 주의

- **이슈나 PR에 원본 문서를 그대로 첨부하지 마세요.** 이름·학번·과목명을 지운 최소 재현 예시로 만들어 올립니다.
- 팀원끼리 데이터를 공유해야 하면 저장소가 아닌 별도 채널로 주고받고, 어디에 뒀는지는 이슈에 기록합니다.
- 사용자가 원문을 삭제할 수 있어야 한다는 것이 제품 원칙입니다 (계획서 3.2). 개발 중에도 같은 태도로 다룹니다.
