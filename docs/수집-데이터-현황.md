## 2. 공개 공지 게시판 (수집 중)

로그인 없이 `httpx` 로 수집. robots.txt 확인, 전 페이지 순회, URL 중복판별.
명령: `python -m src.collect.cli notices all`

| 사이트 키 | 게시판 | 게시판 규모(실측) | 구조/파서 |
| --- | --- | ---: | --- |
| `aisw` | 인공지능학부(학과) | **31건** | 전남대 CMS(artclView) |
| `aicoss` | 인공지능혁신융합사업단 | **435건** | movePageView → view/{id} |
| `nccoss` | 차세대통신혁신융합사업단 | **198건** | 〃 |
| `sojoong` | 소프트웨어중심사업단 | **218건** | 워드프레스 KBoard |

수집 항목: 제목 · URL · 게시일 · 구분값(site 제공) · **본문** · **첨부파일(이름+URL)**
※ 카테고리 **의미 분류**(장학/모집/행사 등)는 아직 안 함 → 이후 `notice_ai-agent`(LLM).

## 2-B. 대외활동·공모전·채용·교육 (전국, 대학 무관)

JNU 무관 전국 대상 사이트. `python -m src.collect.cli external all`
robots 허용된 공개 API 를 그대로 호출(사이트 프런트가 쓰는 요청). **스크롤 N번 = offset 0..20*N**.

| 소스 키 | 내용 | 실측(스크롤2) | 방식 |
| --- | --- | ---: | --- |
| `campuspick_contest` | 공모전 | 60건 | api2.campuspick.com (target=1) |
| `campuspick_activity` | 대외활동 | 60건 | 〃 (target=2) |
| `campuspick_education` | 교육 | 60건 | 〃 (target=3) |
| `campuspick_job` | 채용 | 5건 | /find/job/companies |

- 항목: 제목·주최(company)·**마감일(end_date)**·**기간종료여부(period_ended)**·조회수·URL
- 저장: `data/processed/external/<소스>.json` (id 중복 제거)
- `end_date` 로 마감/진행중 자동 구분.

### 🚫 ipmarket.or.kr (주신 3개 URL) — 목록 아님

- `idrCarbon/idrSafety/idrGlobal.do` 는 **정적 소개 페이지**(기업회원 가입 안내 등)로,
  크롤링할 목록 데이터가 없습니다. robots 는 허용(`Allow: /`)이나 대상이 리스트가 아님.
- 실제 공모/아이디어 목록 URL(예: `ideaStoreList.do`)을 주시면 붙일 수 있습니다.

## 4. 🚫 전남대 공식 홈페이지 — robots.txt 금지 (미수집)

- URL: `https://www.jnu.ac.kr/WebApp/web/HOM/COM/Board/board.aspx?boardID=5`
- **robots.txt: `Disallow: /` (홈·Common·css 만 허용).** 공지 게시판은 금지.
- 수집 계획서 §6.1(robots 준수)에 따라 **크롤링하지 않습니다.**
- 필요 시 **학교에 RSS/API 제공 또는 서면 허가를 요청**한 뒤 진행.

### (참고) 허가 시 바로 붙일 수 있는 구조 — 이미 분석해 둠

- **카테고리**: `searchCate` 파라미터로 선택 (16종)

  | 값 | 카테고리 | 값 | 카테고리 |
  | --- | --- | --- | --- |
  | 0 | 전체 | 12 | 입찰공고 |
  | 5 | 학사안내 | 13 | 채용공고 |
  | 6 | 대학생활 | 14 | IT뉴스 |
  | 7 | 취업정보 | 15 | 공모전 |
  | 8 | 장학안내 | 16 | 모집공고 |
  | 9 | 행사안내 | 17 | 학술연구 |
  | 10 | 병무안내 | 842 | 직원표창공개 |
  | 11 | 공사안내 | 1367 | 행정공고 |

- **공지 여부**: 목록 `번호` 칸이 `공지` 면 상단고정 공지, 숫자면 일반글.
- **카테고리 표기**: 제목 앞 `[학사안내]` 처럼 붙음.
- **기간 종료 여부**: 목록에 마감 뱃지는 없음 → 제목/본문의 마감일(`~8/18` 등)을
  추출해 오늘과 비교해야 함(자유서술이라 이 부분은 LLM 또는 규칙+검증).
- 상세 URL: `board.aspx?boardID=5&bbsMode=view&key={번호}`
- **SSL 주의**: `www.jnu.ac.kr` 은 중간 인증서를 안 보냄 → Sectigo 중간 인증서를
  번들에 추가해야 검증됨(`verify=False` 금지). 이미 해결 코드 있음.

## 5. 데이터 저장 위치 (요약)

모두 `data/` 아래, **git 에 올라가지 않음**(`.gitignore`).

```
data/
├── raw/        원문 보존 (HTML/PDF/ICS)
├── meta/       원문별 메타데이터
├── index/      URL 중복·수정 판별
├── runlog/     실행 이력
├── processed/  구조화 결과 (timetable JSON, notices JSON)
└── sessions/   로그인 세션 쿠키 (민감, 비번 없음)
```

각 파일의 상세 스키마는 [크롤링-매뉴얼.md 5장](크롤링-매뉴얼.md#5-데이터-저장-방식--어디에-어떤-형식으로).

### HF 데이터셋 업로드 현황

- `logan098/Univ-Us_AI-agent` (🔒 private) 에 **공지(구조화)·시간표·계획서 PDF** 업로드됨.
- **세션·이름·학번은 제외.** 시간표는 개인정보 없는 구조화본만.

## 6. 준수 사항 (§6)

- robots.txt 확인 후 허용된 곳만 수집 (공식 홈페이지는 금지 → 미수집)
- 요청 간격 유지, 동시요청 없음, User-Agent 명시
- 개인정보(이름·학번·연락처)·세션은 외부로 내보내지 않음
- 공지 본문·첨부는 각 게시판 저작권에 따름(출처 URL 보관)
