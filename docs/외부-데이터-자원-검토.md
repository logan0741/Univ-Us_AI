## 자원별 상세

### 1. AutoTimeTable-Generator — ❌ 제외
- **무엇**: 유전 알고리즘으로 **시험 시간표를 새로 생성**하는 C#/.NET 데스크톱 앱(대학 과제, 9커밋·방치).
- **왜 안 맞나**: 우리는 시간표를 **읽어오는**(학생의 기존 JNU 시간표 파싱) 쪽이지 **생성**하지 않습니다. 스택도 C#(우리는 Python), **라이선스 없음**(= 기본 저작권, 재사용 불가).
- **도움 방향**: 사실상 없음. "시험 배치 제약" 개념 정도만 참고.

### 2. anakin87/events-scheduling — ⚠️ 참고(형식·평가 설계)
- **무엇**: 이벤트 목록에서 우선순위 가중치를 최대화하도록 **겹치지 않는 일정 선택** → XML로 출력. 영어·합성 600건(RL/GRPO 학습용). Apache-2.0.
- **실사용**: 데이터 자체는 **영어·합성**이라 우리 학습·평가에 직접 투입 부적합.
- **도움 방향**: 우리 "이번주 일정 고르기 / 시간 충돌 처리 / 우선순위" 태스크의 **입력→구조화 출력 형식과 채점(optimal_score) 설계**를 참고. 우리 한국어 정답셋 스키마 짤 때 좋은 본보기. 라이선스 깨끗.

### 3. kizoey/timetable-optimization — ⚠️ 제한적
- **무엇**: 강의평(KLUE) 크롤링 + 이동거리·평점 가중으로 **추천 시간표 생성**. Python/R, 한국어, **라이선스 없음**.
- **실사용**: 우리 핵심(집계·질의응답)과 문제가 다름(생성/추천). 라이선스 없어 **코드 직접 차용은 지양**.
- **도움 방향**: 한국 대학 맥락의 **강의평 텍스트 전처리·NLP 기법** 참고. 로드맵의 "추후: 시간표 추천" 아이디어로만.

### 4. KETI-AIR/aihub_dialog_summarization — ⚠️ 조건부(라이선스·도메인 주의)
- **무엇**: 한국어 **대화 요약** 데이터(AI Hub 원본). HF에는 **로더 스크립트만(17KB)**, 뷰어가 임의 코드 실행을 요구 → 실제 데이터는 AI Hub에서 받아야 함.
- **⚠️ 라이선스**: HF의 Apache-2.0은 **로더 스크립트**에 붙은 것일 뿐, **AI Hub 원데이터는 별도 약관**(회원가입·이용신청, 재배포·상업이용 제한이 흔함). **원 약관 확인 전 배포·상업 사용 금지.**
- **도움 방향**: 요약 기능 보조 학습엔 될 수 있으나 **도메인이 "대화"** 라 우리 "공지·문서 요약"과 다름. 요약 파인튜닝을 한다면 우리 도메인 데이터가 더 낫습니다.

### 5. ai-ml-foundations-book-collection — ❌ 제품 제외 / ✅ 팀 학습용
- **무엇**: AI/ML 교재 **25권 PDF 모음(592MB, 영어)**. 수학·딥러닝·트랜스포머·RL·RAG 등.
- **⚠️ 저작권**: **교재는 저작권 있는 저작물**입니다. HF의 Apache-2.0 태그가 원저작권을 무효화하지 않습니다 → **모델 학습·재배포에 넣지 마세요**(저작권 리스크).
- **도움 방향**: **팀원 공부 자료**로는 훌륭(트랜스포머·RAG·RL 개념 습득). 제품 데이터/학습셋으로는 사용 금지.

### 6. EbanLee/kobart-summary-v3 — ✅ 실사용 후보
- **무엇**: **KoBART 기반 한국어 요약 모델(0.1B)**. transformers로 `BartForConditionalGeneration` 로 바로 사용.
- **실사용**: 0.1B로 아주 작아 우리 **9.5GiB GPU에 여유**([GPU 문서](GPU-환경과-모델-선정.md)), 로컬에서 즉시 돌릴 수 있음. **라이선스 미명시** → 사용 전 확인(베이스 KoBART은 MIT 계열).
- **도움 방향**: 공지·계획서 요약의 **저비용 로컬 베이스라인**. 대형 API(LLM_MAIN)로 요약하기 전에 짧은 공지는 이걸로 처리해 비용 절감. eval에서 "API LLM 요약 vs KoBART" 비교 기준선. **v3는 문장이 파편적**이라니 v2와 품질 비교 필요.

### 7. yulddo/Jia_Secretary_v1 — ⚠️ 참고(톤, 규모 부족)
- **무엇**: 한국어 **비서 대화 20건**(일정·이메일·업무 관리). function calling 아니고 조언형 응답. <1KB.
- **실사용**: **20건뿐**이라 학습엔 태부족, 도구호출도 없어 우리 에이전트와 결이 다름.
- **도움 방향**: 우리 대화 에이전트의 **응답 톤·비서 페르소나** few-shot 예시로 몇 개 참고. 학습 데이터로는 부적합.
